# Spy

**Instant replay for macOS**, built with Swift, SwiftUI, ScreenCaptureKit and AVFoundation.

Spy сохраняет последние минуты экрана по нажатию кнопки или горячей клавиши. Буфер работает в фоне, а перед сохранением можно посмотреть видео и выбрать нужный фрагмент.

Текущая версия: **1.11.1** (сборка 19). Интерфейс на русском языке.

## Скачать приложение

Готовые ZIP и DMG находятся в [релизах GitHub](https://github.com/Pechivoa/Spy/releases/latest). DMG содержит Spy.app, ссылку на «Программы» и инструкцию. Рядом опубликован файл SHA256SUMS.txt.

Публичная сборка не нотариализована Apple и не имеет подписи Developer ID; macOS на другом Mac может ограничить её запуск. Исходники доступны для самостоятельной сборки.

## Исправление в 1.11.1

Полноэкранный плеер с монтажом занимает всю ширину текущего монитора. Панель управления больше не ограничивает размер окна.

## Новое в 1.11.0

- **Заметный полноэкранный просмотр:** текстовая кнопка «На весь экран» находится над видео и в отдельной полоске под ним, включая предпросмотр из мини-окна. Видео разворачивается на текущем мониторе без нового Space macOS. Esc возвращает исходный просмотр.
- **Монтаж на весь экран:** выбор начала и конца, метки на позиции плеера, переключатель микрофона и сохранение фрагмента. Метки буфера сохраняются вместе с роликом; при обновлении снимка остаются метки, которые ещё входят в новый буфер.
- **Покадровая работа:** шаг назад/вперёд по фактическим временным меткам видеокадров, время с миллисекундами и цикл A–B. Можно сохранить один кадр в виде короткого ролика.
- **Звук по приложениям:** «Все приложения» либо «Только выбранные». Выбор звука независим от экрана/окна и микрофона. Если выбранные приложения закрыты, получается тишина с предупреждением; звук остальных приложений автоматически не подставляется. Приложения из списка приватности исключаются также из выбранного звука.
- **Приватные области:** в настройках остановленной записи обновите изображение выбранного экрана/окна, добавьте прямоугольники и включите маски. Области закрываются чёрным до кодирования. Координаты относительны кадру: при изменении расположения окон проверьте их заново. На ранее сохранённые ролики маски не распространяются.
- **HEVC, битрейт и лимит кэша:** по умолчанию остаются H.264 и битрейт качества. HEVC требует доступного аппаратного кодировщика; битрейт можно задать вручную. Лимит в ГБ сокращает кольцевой буфер по реальному размеру готовых сегментов. Последний сегмент, текущий кодировщик, закреплённый просмотр и ручная запись могут превышать лимит — это лимит кольца, а не всего каталога временных данных.

## Возможности

- Кольцевой буфер от 30 секунд до 30 минут; значение 0 выключает повтор.
- Захват выбранного монитора или отдельного окна; 720p/30, 1080p/30, 1080p/60 и нативное разрешение до 4K/60.
- Независимый выбор системного звука и микрофона, выбор устройства микрофона и отдельная громкость.
- Отдельная дорожка микрофона: можно выключить голос в плеере и сохранить копию без него.
- Предпросмотр несохранённого буфера, обновление снимка, миниатюры, метки и обрезка.
- Библиотека видео, избранное, переименование, удаление в Корзину и обновление после изменений через Finder.
- Ручная запись, профили приложений, автоклипы по меткам и автозапуск повтора для выбранных игр.
- Восстановление включённого состояния, сохранение при выходе и восстановление готовых сегментов после сбоя.
- Настраиваемые горячие клавиши, компактное окно, скрываемый индикатор и журнал с экспортом TXT.
- MOV с H.264 либо HEVC и AAC; экспорт MP4. Обработка видео выполняется локально.

## Требования

- Mac с Apple Silicon.
- macOS 14 или новее; запись микрофона требует macOS 15 или новее.
- Xcode 16 или новее либо совместимые Command Line Tools с macOS 15 SDK или новее для сборки.
- Разрешение macOS на запись экрана; разрешение на микрофон, если он выбран.

## Сборка

В корне проекта:

```sh
SPY_SIGNING_MODE=adhoc zsh build.sh "$PWD/build/Spy.app"
open build/Spy.app
```

Скрипт собирает release-версию, генерирует иконку и создаёт `build/Spy.app`. Временная подпись подходит для локальной сборки; после пересборки macOS может запросить разрешения заново.

Для повторных сборок с одной локальной подписью:

```sh
zsh build.sh "$PWD/build/Spy.app"
```

Этот режим использует `sign-local.py` и отдельную связку ключей в `~/Library/Application Support/SpySigning`. Доверие сертификату для подписи кода настраивается пользователем; скрипт не меняет доверие или разрешения записи автоматически. Приватный ключ и пароль создаются локально и не входят в репозиторий. Для публичного распространения можно использовать собственный Developer ID и нотариализацию Apple.

Чтобы установить собранное приложение, перенесите `build/Spy.app` в папку «Программы».

## Упаковка релиза

После сборки приложения:

```sh
zsh package-release.sh "$PWD/build/Spy.app" "$PWD/build/release"
```

Скрипт проверит подпись приложения и создаст ZIP, DMG и SHA256SUMS.txt. Он не меняет доверие сертификатов, не выдаёт системные разрешения и не выполняет нотариализацию.

## Первый запуск

1. Выберите экран либо окно, длительность буфера и качество.
2. Выберите системный звук и/или микрофон.
3. Нажмите «Включить повтор» и предоставьте необходимые разрешения macOS.
4. Для сохранения нажмите «Сохранить повтор» или `⌥⌘S`; для просмотра буфера — `⌥⌘P`.

Каждый снимок предпросмотра фиксируется на указанное время. «Обновить буфер» получает свежий снимок без остановки записи. Кнопка «На весь экран» над видео и в отдельной полоске плеера доступна и в предпросмотре буфера, и в сохранённых видео, в том числе во время записи. Выход — Esc или «Выйти». Видео разворачивается на текущем мониторе без создания отдельного Space macOS; позиция и выбранный звук сохраняются.

Захватывается один выбранный монитор. Другие мониторы не включаются в видео автоматически.

Полная [инструкция пользователя](README.txt) описывает горячие клавиши, хранение, восстановление, звук и настройки.

## Проверки

В проекте есть встроенные исполняемые проверки. Каждому запуску передавайте отдельный новый каталог для временных результатов:

```sh
swift build -c release
.build/release/Spy --self-test /tmp/spy-core-check
.build/release/Spy --audio-test /tmp/spy-audio-check
.build/release/Spy --buffer-preview-test /tmp/spy-preview-check
.build/release/Spy --microphone-library-test /tmp/spy-microphone-check
.build/release/Spy --capture-reliability-test /tmp/spy-capture-check
.build/release/Spy --owned-frames-test /tmp/spy-frames-check
.build/release/Spy --editor-test /tmp/spy-editor-check
.build/release/Spy --application-audio-test /tmp/spy-app-audio-check
.build/release/Spy --capture-tuning-test /tmp/spy-format-check
.build/release/Spy --diagnostics-test /tmp/spy-diagnostics-check
```

Проверки используют синтетическое медиа и изолированные временные данные. Они не заменяют проверку реального захвата с разрешениями macOS.

## Структура

| `Sources/` | Захват, кольцевой буфер, звук, интерфейс, библиотека и встроенные проверки |

## Данные

По умолчанию видео хранятся в `~/Movies/Spy`, настройки и журнал — в `~/Library/Application Support/Spy`, временные сегменты — в `~/Library/Caches/local.spy.mac`.

Записи экрана, пользовательские настройки, журналы, локальные аудиты и ключи подписи в репозиторий не включены.
